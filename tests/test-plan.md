# Тест-план «12 недель»

Нумерация: `F<сценарий>-H<n>` — основной путь, `-E<n>` — пограничный случай, `-N<n>` — негативный.
Колонка «Как» — `авто` (tests/e2e.py), `живой` (проверка на опубликованном сайте и реальном Supabase), `ручной` (нужен человек: письма, установка на телефон).
