# 12 недель

Личный трекер по системе «12 недель в году»: видение, цели и тактики на 12 недель, оценка исполнения с порогом 85%, еженедельные обзоры, блоки времени и прокачка уровня с достижениями.

Статическое веб-приложение (PWA): работает без сборки, устанавливается на телефон, хранит данные локально и синхронизирует их через Supabase.

- `index.html` — всё приложение
- `config.js` — адрес проекта Supabase и публичный ключ
- `sw.js`, `manifest.webmanifest`, `icon*` — установка и офлайн-режим
